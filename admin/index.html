Cara Kerja Saat Ini

Karena situs di-deploy di GitHub Pages (static hosting), sistem order menggunakan kombinasi:

  • WhatsApp Deep Link — langsung mengirim data pesanan ke nomor 08515-9922-358
  • Google Sheets + Apps Script (opsional) — menyimpan data ke spreadsheet & kirim notifikasi email

1. Setup Google Sheet (Database Gratis)

  1. Buat Google Sheet baru, beri nama MyRep Orders
  2. Buat header di baris 1: Timestamp | Nama | Alamat | Email | WA | Paket | Catatan | Status
  3. Buka Extensions → Apps Script
  4. Paste kode dari file apps-script.js (ada di folder ini)
  5. Deploy sebagai Web App → Execute as: Me → Who has access: Anyone
  6. Copy URL Web App, lalu paste ke js/app.js bagian APPS_SCRIPT_URL
Buka Google Sheets

2. Notifikasi

  • WhatsApp: Otomatis terbuka saat pelanggan submit (ke nomor Teddy)
  • Email: Apps Script bisa kirim email ke admin@silverhawk.web.id setiap ada order baru
  • WA Admin: Bisa ditambahkan via CallMeBot / WA API berbayar, atau cukup pantau WA pribadi

3. Lihat Pesanan

Setelah setup Sheet + Apps Script, pesanan akan muncul di spreadsheet. Anda juga bisa publish Sheet sebagai CSV dan load di sini.

Untuk login Google penuh (admin@silverhawk.web.id), disarankan menggunakan Firebase Authentication (gratis) + Firestore, atau cukup proteksi password sederhana seperti halaman ini.
